The brand gold #B8934A is used for warnings, errors and "unavailable" labels — the messages that matter most when something goes wrong.

Found in 52 places across src/. Measured contrast on the page background: 2.69:1. WCAG AA requires 4.5:1. In sunlight, on a phone, this is close to invisible.

Same hue, same saturation, darker. I kept #B8934A exactly as it is for everything non-text — star ratings, tinted backgrounds, highlight borders — because decorative fills are exempt and the brand look shouldn't shift. Only the 52 places where gold is text move to sandink.

2 Input fields are almost invisible

A field's interior is #FBF7F1 sitting on a white card, with a #E8E1D6 border.

Field interior vs card: 1.07:1. Border vs card: 1.30:1. WCAG 1.4.11 requires 3:1 for the boundary of a control. Placeholder text is 2.45:1 — it's mist at 60% opacity.
قبل — current1.30:1 FAIL

Tap-target is fine (48px) — the problem is you can barely see where the box is.

بعد — proposed3.40:1 PASS

Border #A3875C on .field only. Placeholder goes to full-opacity mist (5.35:1).

Card borders stay light. Only form controls get the stronger edge — that's what the rule is actually about, and darkening every card border would make the whole app look boxed-in.

3 Tap targets are too small for a driver on a scooter

Tabs and the compact action buttons sit at 32–36px tall. Apple asks for 44, Google for 48.

Found 39 buttons using py-1/py-1.5, plus 9 tab bars. These pass the bare WCAG AA minimum (24px) but fail every platform guideline — and they're the controls drivers and vendors hit one-handed, outdoors, in a hurry.
قبل — current32–36px
dashed outline = the actual tappable area
بعد — proposed44px min
same type size, same colours — only the padding grows

Font sizes don't change. This is padding only, so nothing reflows sideways and no Arabic text re-wraps. Rows get a few pixels taller.

4 Modals can't be dismissed with Escape

Try it in both panes below — open the dialog, then press Escape (or tap outside).

Of the 10 files with a full-screen fixed inset-0 overlay, 9 have no Escape handling at all. Only CustomerLogin has it. This is also how PhonePrompt became a trap earlier — no keyboard exit, and on desktop admin work it means reaching for the mouse every time.
قبل — currentEscape does nothing

Also: focus isn't trapped, so Tab walks off into the page behind the overlay.

بعد — proposedEscape closes

Escape closes, focus is trapped inside while open, and returns to the button on close.

One shared hook. Rather than patch nine files by hand, I'd add a useDismissable() hook that wires Escape, focus trapping and focus restore, and call it from each overlay — so the tenth modal someone adds gets it for free.

5 Numbers switch alphabets mid-screen

Dates and times render in Arabic-Indic digits; prices, order numbers and distances render in Latin.

Every date goes through toLocaleDateString('ar-EG'), which produces ٤ أغسطس and ٣:٣٠ م. Every price is a raw JS number, producing 185 ج.م. Both appear on the same order card.

طلب #14 · مطعم البحر

الثلاثاء، 4 أغسطس · 3:30 م

الإجمالي 185 ج.م · المسافة 7.4 كم

Standardise on Latin, not Arabic-Indic. Prices, phone numbers and order IDs are already Latin everywhere and would be much more disruptive to convert; the phone inputs are even dir="ltr". The fix is one locale string — 'ar-EG' becomes 'ar-EG-u-nu-latn' in the 11 places that format a date or time. Arabic month and day names are unchanged. Say the word if you'd rather go the other way — all-Arabic-Indic is defensible, it's just a much larger change.

6 No field is connected to its label

The labels look right, but nothing links them to the input underneath.

51 <label> elements, 0 with htmlFor. 107 inputs, 0 with aria-label. Two consequences: a screen reader announces the field with no name, and tapping the label text doesn't focus the field — which on a phone is a target you'd expect to work.
قبل — currentunnamed
VoiceOver reads:
"text field, empty"

Tap the words "رقم الموبايل" above — nothing happens.

بعد — proposednamed
VoiceOver reads:
"رقم الموبايل, text field, empty"

Tap the words "رقم الموبايل" above — the field focuses.

This is the biggest change by line count — 51 labels and 107 inputs need matching ids. It's mechanical and safe, but it's most of the diff. If you'd rather keep batch 6 small, this is the one to split into its own pass.
